# Python Calculator 🧮

A simple calculator built with Python. This project allows users to perform basic mathematical operations such as addition, subtraction, multiplication, and division.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Easy-to-use command-line interface

## Requirements

- Python 3.x

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
python calculator.py
